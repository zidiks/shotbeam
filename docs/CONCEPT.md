# Shotbeam — концепция v2 (local-first + MCP)

Рабочее название: **Shotbeam**. Это локальная студия коротких видео (Reels / Shorts / TikTok) на
компьютере. Главный интерфейс — **MCP**: «думает» Claude (Code или Desktop, по подписке), а
приложение даёт ему руки (медиатека, нарезка, озвучка, рендер). Плюс свой UI с редактором, чтобы
докрутить руками. Прошлая концепция (облачный SaaS из заметок «AI Content Studio» в FixNote)
урезана до того, что нужно одному человеку на своём компе.

## 1. Что умеет

1. **Проекты** (Level Legends, FixNote, …) с brand kit: цвета, шрифты, тон, правила.
2. **Источники**: локальные папки и Google Drive. Пока Drive подключается через Google Drive for
   Desktop (папка `G:\Мой диск\…` = обычный локальный источник), API-коннектор будет позже.
   Оригиналы не копируются, индекс и превью лежат в библиотеке.
3. **Индексация медиа**: метаданные, превью, прокси 540p, транскрипт со словами (faster-whisper),
   сцены (ffmpeg scdet), громкость (ebur128), контактные листы (сетки кадров), кандидаты на
   «сочные моменты».
4. **Сочные моменты**: аппка считает сигналы (речь, пики громкости, смены сцен, движение), Claude
   смотрит контактные листы и транскрипт через MCP и выбирает отрезки. Отдельного API для видео нет:
   кадры и текст отдаются Claude по подписке.
5. **Референсы**: ссылка YouTube / Instagram / TikTok / X → yt-dlp → такая же индексация → Claude
   разбирает (хук, ритм, структура, типографика, звук) → **Формат**.
6. **Форматы** (Format Recipe): переиспользуемый шаблон ролика: структура по битам (хук, тело, CTA),
   тайминги, стиль сабов, музыка (настроение / BPM), голос, моушн-шаблоны, переменные. Формат
   доводится постепенно в чате с Claude (`update_format`) и в UI.
7. **Озвучка**, провайдер выбирается перед генерацией:
   - **Fish Audio API** (`s2.1-pro`, `s2.1-pro-free`), клон голоса через `/model`;
   - **Fish локальный** — свой сервер fish-speech (`tools/api_server.py`) по URL: дома мощный
     комп, здесь можно указать адрес или арендованную GPU;
   - **Kokoro** (локально, без клона, быстрые черновики; нет русского);
   - **Chatterbox Multilingual** (локально, клон по референсу, 23 языка вкл. русский).
   Режимы: текст → свой голос (в том числе EN/ES), чистка живого дубля, точечная перегенерация слов.
8. **Музыка**: своя папка с треками → локально BPM и биты → Claude тегает настроение и подбирает →
   монтаж в бит. Трендовые звуки соцсетей не вшиваются в рендер, в формате остаётся пометка
   «добавить при публикации».
9. **Моушн-дизайн**, движок выбирается перед генерацией: **Remotion** (React) или **HyperFrames**
   (HTML/GSAP, Apache 2.0). Каждый моушн-шаблон привязан к своему движку; в одном ролике можно
   смешивать сцены разных движков (рендер по отдельности → склейка ffmpeg).
10. **Timeline-lite редактор**: превью, дорожки (видео / аудио / текст / моушн), трим, перестановка,
    сабы, оверлеи из шаблонов формата.
11. **Рендер**: ffmpeg (NVENC, если есть) → MP4 9:16 / 1:1 / 16:9.
12. Позже: аналитика форматов (YouTube Analytics и т.д.), Trend Radar, генеративное видео.

## 2. Чего нет (решено)

Supabase / S3 / n8n / облачные очереди, мультиюзер и роли, автопостинг в соцсети, экспорт в
DaVinci, Gemini API. Всё лежит локально.

## 3. Архитектура

```
Claude Code / Desktop ──stdio──▶ apps/mcp ──HTTP──▶ packages/engine (Node, localhost)
                                                      │  SQLite (node:sqlite), библиотека файлов
UI (apps/web в Tauri apps/desktop) ──HTTP + SSE──────▶│  jobs: ffmpeg, python-воркер, yt-dlp,
                                                      │  TTS-провайдеры, Remotion, HyperFrames
```

- **packages/core**: типы и zod-схемы (проект, ассет, референс, формат, композиция/таймлайн),
  чистые операции над таймлайном. Без IO.
- **packages/engine**: локальный сервер. БД, библиотека, источники, индексация, очередь задач,
  провайдеры голоса, рендер. Один источник правды: UI и MCP меняют одно и то же, а изменения
  прилетают в UI через SSE.
- **apps/mcp**: тонкий stdio MCP-клиент к engine; если engine не запущен, поднимает его сам.
- **apps/web**: React UI на дизайн-системе FixNote (`packages/ui`).
- **apps/desktop**: Tauri 2 оболочка, запускает engine.
- **Python-воркер** (`packages/engine/python/worker.py`, venv в библиотеке): faster-whisper,
  yt-dlp, Kokoro, Chatterbox, librosa. Ставится по кнопке, тяжёлое опционально.

**Композиция** (таймлайн) — один JSON-документ. Его правят и MCP-тулзы, и редактор.

## 4. Железо и деньги

- Этот комп: i3-10100F, 16 ГБ, GTX 1050 Ti 4 ГБ. Whisper small/medium, Kokoro и рендер тянет.
  Fish локальный (S2 Pro ~5B, 12–24 ГБ VRAM) — только на домашнем мощном компе.
- Платно: Fish API (≈ $15 / 1M байт UTF-8; кириллица = 2 байта; есть `s2.1-pro-free`),
  опционально генерация музыки. Claude — подписка.
- Веса Fish S2 Pro под Research License: для коммерческого контента нужна лицензия Fish.

## 5. Этапы

1. Каркас: монорепа, engine + БД, источники, индексация, MCP, базовый UI. ← сейчас
2. Голос (Fish API / Fish local / Kokoro / Chatterbox), клон, сабы со словами.
3. Референсы + форматы, разбор через MCP.
4. Рендер композиции (ffmpeg) + моушн (Remotion / HyperFrames).
5. Timeline-lite редактор.
6. Музыка: библиотека, биты, монтаж в бит.
7. Аналитика форматов.
