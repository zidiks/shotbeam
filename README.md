# Shotbeam

Локальная студия коротких видео (Reels / Shorts / TikTok), которой управляет Claude через MCP.
Медиатека из локальных папок и Google Drive for Desktop, поиск «сочных» моментов, разбор
референсов по ссылкам, форматы-шаблоны, озвучка (Fish Audio API / локальный Fish / Kokoro /
Chatterbox), моушн (HyperFrames / Remotion), монтаж на таймлайне и рендер в ffmpeg.

Концепция и решения: [docs/CONCEPT.md](docs/CONCEPT.md).

## Что нужно

- Node 24+, pnpm, ffmpeg и ffprobe в PATH
- Python 3.10–3.12 (локальные модели ставятся из приложения: Настройки → Локальные модели)
- Для десктопа: Rust (stable) и WebView2 (в Windows 11 уже есть)

## Запуск

```bash
pnpm install
```

Браузерная версия (движок + UI на http://localhost:5180):

```bash
pnpm dev
```

Десктоп (окно Tauri; движок запускается сам):

```bash
pnpm dev:desktop
```

## Подключить AI-помощника

В десктопе: **Настройки → Подключённые приложения (MCP)** → «Добавить в Claude Desktop»,
«Добавить в Cursor» или «Добавить в Codex». Затем перезапустите выбранное приложение.
Shotbeam добавляет только свой сервер, сохраняет остальные настройки и делает резервную копию
существующего конфига с расширением `.shotbeam-backup`. В браузере доступно копирование
настроек JSON для ручного подключения.

Для Claude Code:

```bash
claude mcp add --scope user shotbeam -- node "D:/prjoects/shotbeam/apps/mcp/bin/shotbeam-mcp.mjs"
```

Библиотека (база, превью, голоса, рендеры) лежит там, куда указывает `~/.shotbeam.json`.

Правый клик по карточке видео, формату, голосу или элементу таймлайна открывает меню действий.
В разделе **Голос → Клонировать голос** есть готовый текст для записи и режим собственной речи.
Если прочитан весь предложенный текст, его можно подставить как расшифровку отдельной кнопкой;
иначе оставьте поле пустым для распознавания или укажите фактически произнесённый текст.
